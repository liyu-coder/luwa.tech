# Luwa Tesemma — Senior Software Engineer & FinTech Architect

A modern, high-performance, responsive portfolio web application for **Luwa Tesemma**, Senior Software Engineer at Sidama Bank (formerly at Siinqee Bank). Showcasing production banking microservices, global e-commerce platforms, national job portals, charity platforms, and hospitality SaaS systems.

🌐 **Live Experience:** [luwa-portfolio.vercel.app](https://github.com/liyu-coder/Luwa-Tech-)

---

## ✨ Features & Highlights

- **Dynamic Hero Section**: Multi-role typewriter animation, quick stats bar (4+ Years Exp, 2 Top Banks, 15+ Production Deployments, 99.9% Uptime), live availability badge, and direct CTAs.
- **Interactive Project Showcase**:
  - **Sheba Goods**: Premier Ethiopian specialty e-commerce marketplace exporting coffee, traditional attire (Habesha Kemis, Netela), spices, and leather goods globally ([shebagoods.com](https://shebagoods.com/)).
  - **Fayda Jobs**: Comprehensive Ethiopian career discovery portal with Telegram bot alerts and resume builder ([faydajobs.com](https://www.faydajobs.com/)).
  - **Mikita Foundation**: Heartwarming charity platform supporting pediatric brain cancer (DIPG) patients and active relief campaigns ([mikita-foundation.vercel.app](https://mikita-foundation.vercel.app/)).
  - **Mikita Café Connect**: Digital café ordering & table reservation system with omnichannel direct checkout ([mikita-cafe-connect.vercel.app](https://mikita-cafe-connect.vercel.app/)).
  - **SMH Hotel Management System**: Enterprise hospitality SaaS featuring interactive room booking calendar, guest check-in/out workflows, and revenue analytics.
  - **Tsidu Solid Waste Management**: Smart municipal platform for route tracking and civic waste management.
  - **Core Banking Microservices Gateway**: High-throughput transaction engine with atomic ledger consistency, sub-50ms API latency, and PCI-DSS compliance.
- **Interactive Deep-Dive Project Modal**: Click any project to inspect problem statement, key capabilities, architecture breakdown, and live/source links.
- **Categorized Technical Arsenal**: Interactive skill filters across Frontend, Backend & Systems, Databases & Storage, DevOps & Tooling, and FinTech Architecture.
- **Career & Education Timeline**: Detailed career progression from Siinqee Bank to Senior Software Engineer at Sidama Bank, complete with quantifiable impact metrics and technology tags.
- **Interactive Curriculum Vitae (CV) Modal**: In-browser preview with one-click print/PDF export and structured experience summary.
- **Endorsements & Recommendations**: Testimonials from engineering leaders and colleagues highlighting architectural excellence and code quality.
- **Functional Contact Section**: Interactive message form with live state validation, one-click copy email button, and direct communication channels.
- **Modern Design & Ambient Aesthetic**: Built with dark-mode glassmorphism, responsive mobile drawer menu, smooth ScrollSpy navigation, and ambient glowing mesh orbs.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/liyu-coder/Luwa-Tech-.git

# Navigate to project directory
cd Luwa-Tech-

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build

```bash
# Compile and bundle for production
npm run build

# Preview production build locally
npm run preview
```
